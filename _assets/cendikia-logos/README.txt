Cendikia logo package

svg/       Vector masters. Symbol files are pure geometry. Lockups embed a Plus Jakarta Sans SemiBold subset, so they render without the font installed.
png/       Transparent PNGs (symbols 512px, lockups 4x).
favicon/   favicon.ico (16/32/48), favicon.svg, PNG 16-512.
app-icon/  Rounded icon 192/512 (Android, PWA), square 180 (iOS apple-touch-icon) and 1024 (app stores).

Colours
Ledger Navy   #10263F
Session Teal  #1F9E98
Teal on dark  #3CC2BA

Use -color on light backgrounds, -color-dark or -white on dark backgrounds, -black for single-colour print.
Minimum symbol size 16px. Clear space: 1/4 of symbol height on every side.
